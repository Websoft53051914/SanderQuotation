# Velzon CRUD 文字規格模板

填寫格式：

-   欄位名稱｜型態
-   欄位名稱｜型態｜選項（只有 `select` / `radio` / `checkbox-group` 通常需要）
-   欄位名稱｜型態｜必填
-   欄位名稱｜型態｜選項｜必填

規則：

-   只有必填才標註 `必填`。
-   沒標註 `必填` 預設就是非必填。
-   如果沒有選項，不用留空欄位，直接寫「欄位名稱｜型態」即可。
-   輸入片段順序有誤時，AI 仍需以關鍵字判斷：型態、選項、是否必填。

## 欄位型態速查

1. `text`：一般輸入框
2. `number`：數字
3. `textarea`：多行文字
4. `select`：下拉選單（Choices.js）
5. `radio`：單選
6. `checkbox`：單一勾選框
7. `checkbox-group`：多個勾選框
8. `datepicker`：日期時間
9. `file`：檔案上傳

常用寫法範例：

-   關鍵字｜ text
-   狀態｜ select ｜全部/草稿/簽核中/已生效
-   區域｜ radio ｜全部/國內/國外｜必填
-   是否啟用｜ checkbox
-   權限項目｜ checkbox-group ｜查詢/新增/修改/刪除｜必填
-   生效日｜ datepicker ｜必填
-   備註｜ textarea
-   匯入檔案｜ file

## 填寫範例（複製後調整）

根據 /Velzon_TEMPLATE_PACK/CRUD_IMPLEMENTATION_SKILL 內容產生對應畫面
本次建立功能名稱為：YourFeatureName
頁面模式：單頁 Index + Modal
資料來源模式：前端寫死

### 1. 查詢條件

1. 關鍵字｜ text
2. 建立人｜ text
3. 狀態｜ select ｜全部/草稿/簽核中/已生效

### 2. 列表欄位

1. 編號
2. 名稱
3. 類型
4. 版號
5. 生效日
6. 狀態
7. 建立人
8. 更新時間

### 3. 編輯欄位

1. 名稱｜ text ｜必填
2. 版號｜ number ｜必填
3. 類型｜ select ｜管理/品質/資訊/安全｜必填
4. 部門/建立人｜ text
5. 套用對象｜ checkbox-group ｜一般員工/主管/稽核/系統管理員｜必填
6. 風險等級｜ radio ｜低/中/高｜必填
7. 開始日期時間｜ datepicker ｜必填
8. 結束日期時間｜ datepicker ｜必填
9. 說明｜ textarea
10. 附件｜ file
