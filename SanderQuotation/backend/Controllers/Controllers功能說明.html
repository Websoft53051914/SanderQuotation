ApiBaseController.cs 基底

功能說明：所有 backend API Controller 的 JSON／分頁共用基底，不對外直接路由。

參考功能名稱與用途：供業務 Controller 呼叫統一回應格式與 PageEntity 轉換。

成員主要功能
ErrorMsgs累積處理錯誤訊息
GetPageEntity前端分頁/排序 → PageEntity
JsonSuccess / JsonOK成功：{ Success: true, Data }
JsonValidFail 等失敗：{ Success: false, Message }
GetDomainName目前請求網域 URL

前端對應：無（由業務頁 AJAX 間接使用）。

BaseProjectController.cs 基底

功能說明：專案級基底：JWT 使用者、多語系訊息、ControlLog、BL 工廠與各模組 GetBl*。

成員主要功能
OnActionExecutingClaims → UserInfo
GetBLInstance<T>建立 BL 並注入 Session/組態
GetMsgmessage:zh-tw:{key}
LogError / LogSuccess操作日誌
GetBlEsFileTransferUpload 等延遲建立各模組 BL

前端對應：無。

AuthController.cs API

api/auth — 登入、登出與 JWT Cookie。

前端：/Login → Views/Login/Index.cshtml（AuthDoPost）；登出 _topbar → LogoutDoPost。

HTTPAction功能
POSTAuthDoPost帳密驗證、JWT Cookie、回傳登入資料
POSTLogoutDoPost登出並清除狀態

QuotationResultController.cs API

api/QuotationResult — 定時查價結果、明細、重新查價、快查、決策與價格分群。

前端：/QuotationResult、/QuotationResult/Edit/{id}；_QuickPartSearch、_SanderModuleItemPicker。

依賴：QuotationHandler、ExternalQueryExecuteHandler、多個 GetBl*（或 IQuotationResultAppService 若已委派）。

區塊HTTPAction功能
查詢GETGetPageList分頁清單
查詢GETGetById單筆明細（表頭+料項+Mouser/DK）
操作POSTReInternalQuotation更新型號並重新內部查價
操作POSTReExternalQuotation重新 Nexar 外部查價
操作POSTCheckInStockPriceMouser+DK 現貨價寫入 DB
快查GETGetCustomerList客戶下拉
快查GETQuickPartMatch僅查料（不寫 DB）
快查GETQuickPricing勾選內部/外部/現貨（不寫 DB）
決策GETGetDecisionLogs決策歷程
決策GETGetPriceClusterPageList價格分群分頁
