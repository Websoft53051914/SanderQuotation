Services/QuotationResult — 三個 .cs 檔功能說明

路徑：SanderQuotation/backend/Services/QuotationResult/
產生目的：說明應用服務層三個檔案的分工與呼叫關係。

1. IQuotationResultAppService.cs（介面）

角色：定義「定時查價結果」應用層要對外提供的能力，讓 QuotationResultController 只依賴介面，不直接寫 BL／查價流程。

內容：方法契約（簽名 + XML 註解），不包含實作。

主要方法

方法用途
GetPageList分頁清單（BOM 上傳檔／查價結果）
GetById單筆明細（表頭 + 料項 + Mouser/DigiKey）
ReInternalQuotationAsync更新型號並重新內部查價、寫入 DB
ReExternalQuotationAsync重新 Nexar 外部查價、寫入 DB
CheckInStockPriceAsyncMouser + DigiKey 現貨價寫入 DB
BuildQuickSearchResultAsync快查：查料 + 內部查價（不寫 DB）
BuildQuickPartMatchResultAsync快查：僅查料比對（不寫 DB）
BuildQuickPricingResultAsync快查：依勾選執行內部/外部/現貨（不寫 DB）
GetCustomerList客戶下拉選項
GetDecisionLogs料項決策歷程
GetPriceClusterPageList價格分群採購紀錄分頁

2. QuotationResultAppService.cs（實作）

角色：實作 IQuotationResultAppService，將 Controller 的業務邏輯集中在應用服務層。

依賴與職責

  • BL：EsFileTransferUploadBL、BomFileContentBL、HandleQuotationBL、TBBomFileQuotationBL 等 — 查詢與持久化。
  • QuotationHandler：內部查價、外部 Nexar、查料比對（RunInternalAsync、RunExternalAsync、RunPartSearchAsync）。
  • 外部查價：IExternalQueryExecuteHandler / ExternalQueryExecuteHandler — Mouser、DigiKey 現貨價。
  • AutoMapper：組裝 QuotationFileEditVM、QuotationItemVM 等。

行為區分

  • 寫入類（重新查價、現貨價）→ 回傳 QuotationResultServiceResult（成功或「資料不存在」等）。
  • 快查類 → 回傳匿名物件，不寫 DB，由 Controller 包成 JsonSuccess。

輔助方法

方法用途
GetProcessStatusText（static）將 ProcessStatus 代碼轉中文描述
BuildPageEntity（private）將分頁/排序請求轉成 PageEntity

3. QuotationResultServiceResult.cs（結果 DTO）

角色：寫入類操作的簡單回傳包，避免 AppService 直接依賴 HTTP／JSON 格式。

成員用途
Success是否成功
ErrorMessage失敗時的業務訊息（例如「資料不存在」）
Ok()建立成功結果
Fail(message)建立失敗結果

Controller 依 Success 轉成 JsonOK 或 JsonValidFail(ErrorMessage)。

呼叫關係

QuotationResultController │ 注入 ▼ IQuotationResultAppService ←── 契約（介面） │ 實作 ▼ QuotationResultAppService ←── BL / QuotationHandler / 外部 API │ 寫入結果 ▼ QuotationResultServiceResult ←── Success / ErrorMessage │ ▼ Controller → JsonSuccess / JsonOK / JsonValidFail

一句話：介面定義「能做什麼」；QuotationResultAppService 負責「怎麼做」；QuotationResultServiceResult 負責「成功還是失敗、錯誤訊息是什麼」。
