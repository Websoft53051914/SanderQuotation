## 1. 系統概述

本系統為 BOM 智慧查價系統，整合系統帳號權限管理、資料同步排程作業與採購查價流程，協助企業採購人員以自動化方式完成 BOM 料號比對、內部採購價格查詢及外部市場報價取得，最終產出含建議價格的查價結果供採購確認。

**系統模組架構：**

| 模組 | 說明 |
|------|------|
| 系統管理 | 管理使用者帳號、角色權限與操作記錄 |
| 查價轉檔執行模組 | 設定資料來源、建立同步規則、排程自動執行、監控執行狀態 |
| 採購管理 | BOM 上傳、查價結果查看、單一料號快查 |
| AI資料管理 | 歷史資料上傳 |

**採購核心操作流程：**

```
採購上傳 BOM → 選擇客戶 → 系統自動查料（內部比對）→ 內部查價 → 外部查價 → 產出結果
```

## 3. 查價轉檔執行模組

查價轉檔執行模組負責管理資料來源連線、定義資料同步與檔案匯入規則，並透過排程自動執行，將外部資料同步至本系統，作為後續查料與查價的資料基礎。

> **模組說明：** 此模組一般由系統建置階段完成初始設定，日後依資料來源變動進行維護。正常運作期間由排程自動執行，使用者不需頻繁操作。

**欄位對應設定**

每筆欄位對應包含：

| 子欄位 | 說明 |
|--------|------|
| 來源欄位 | 來源資料表的欄位（系統自動載入） |

- **視覺化條件設定**：以介面選擇欄位、條件與值（支援 AND / OR 組合）
- **手動輸入模式**：直接輸入條件語句（供進階設定使用）

#### 操作功能

- 新增 / 編輯 / 刪除（支援批次刪除）
> **刪除說明：** 如果排程設定 有使用到資料表轉檔設定，那麼不能刪除該筆資料表轉檔設定

## 7. 狀態碼定義

| `4`    | 已查價   | 內部 + 外部查價完成                                     |
