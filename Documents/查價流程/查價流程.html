步驟說明程式位置
1 應用程式啟動，SourceScheduleHostService 將資料庫中所有啟用排程以 Hangfire 掛載為定時工作 backend/Jobs/SourceScheduleHostService.cs
2 TransferJob.Run() 依 OtherTransferSettings 遍歷，遇 ScheduleCycleActionTypeEnum.PriceSearch 時取出 PriceSearchJob 並呼叫 ExecuteAsync() backend/Jobs/TransferJob.cs
3 先呼叫 QuotationHandler.AuthorizeExternalAsync() 取得 Nexar Token，再查詢所有 ProcessStatus = PendingPricingSearch(3) 的上傳檔案，逐一呼叫 ProcessUploadAsync() backend/Jobs/PriceSearchJob.cs
4 取出該上傳下所有 BomFileContent，對每筆呼叫 QuotationHandler.RunAsync()，完成後統一呼叫 HandleQuotationBL.DoSaveFullSearchResult()，ProcessStatus 更新為 PricingDone(5) backend/Jobs/PriceSearchJob.cs

Step 1：以 MPN 查詢細節

步驟說明呼叫方法
1-1以 MPN 查關鍵字索引（Similarity 搜尋）TBSanderModuleItemKeywordBL.GetListMatchLongDesc(mpn, null)
1-2AI 語意比對，確認 SimilarityScore = 1ExtractKeywordHandler.MatchKeyword() → backend/AI/ExtractKeywordHandler.cs
1-3消歧義：LongDesc 欄位優先；依 No 升冪排序—
1-4取第一筆，查該料品類別是否需比對廠牌SanderModuleItemBL.GetOneInfoByNo(dm.No)
1-5a不需比對廠牌 → 直接命中，IsRecommendedNo = false結束
1-5b需比對廠牌且廠牌欄空白 → Fallback 建議料號—
1-5c需比對廠牌且廠牌有值 → AI 比對廠牌ExtractKeywordHandler.MatchKeyword(manufacturer, dm.No)
1-5d廠牌一致 → 完全命中；廠牌不符 → Fallback 建議料號—

Step 3：以 Description 向量查詢細節

步驟說明呼叫方法
3-1AI 標準化 Description（正規化電子規格單位：OHM/NF/UF/V/W）ExtractKeywordHandler.StandardizeSearchKeyword(description)
3-2對標準化後字串取 Embedding 向量ManualBatchEmbedding.FillEmbed() → backend/AI/ManualBatchEmbedding.cs，TaskType: RETRIEVAL_QUERY
3-3以向量做相似度搜尋，取第一筆建議料號TBSanderModuleItemKeywordBL.GetListMatchDescription(vectorString)
3-4結果設 IsRecommendedNo = true（建議料號，需人工確認）—

客戶承認料解析（ResolveCustomerApprovedPartsAsync）

位置：backend/Models/QuotationHandler.cs（客戶承認料 partial class）

步驟說明呼叫方法
A-1無 customerCode → 回傳 null（不過濾承認料）—
A-2以 CustomerCode 查 ReportItemCustomer，取 VariantCode 清單ReportItemCustomerBL.GetListByFilter()
A-3查無 Variant → 回傳 null—
A-4以 ItemNo + VariantCode 查 SanderModuleItemVariantSanderModuleItemVariantBL.GetListByFilter()
A-5aFlagNeedExtractKeyword = 0 → 直接取 CustomerApprovedPartCsv（CSV 分割）—
A-5bFlagNeedExtractKeyword ≠ 0 → AI 從 Description/Description2 抽取 MPNExtractKeywordHandler.ExtractKeyword([fakeItem])
A-5c抽取後回寫 Variant：FlagNeedExtractKeyword = 0，CustomerApprovedPartCsv = 抽取結果SanderModuleItemVariantBL.DoUpdateExtractResult()

AI 採購價格分析（OrderPriceDecison.Search）

位置：backend/AI/OrderPriceDecison.cs

步驟說明
D-1歷史採購依 UnitCostLcy 分群，計算各價格出現次數
D-2若只有一筆 → 直接使用
D-3多筆 → 呼叫 Gemini（Semantic Kernel Chat Completion）以 System Prompt 分析高低價群
D-4AI 判定有高低價群 → 取低價群最近一筆採購（依 DocumentDate 降冪）
D-5AI 無法分群（價格差異不明顯）→ 取最近一筆採購
D-6回傳 InternalPurchaseRecordVO：單價（原幣 + 台幣）、供應商、採購日期、高低價群範圍

Token 取得（Authorization）

步驟說明
T-1先查 MemoryCache（key: NEXAR_ACCESS_TOKEN），有效則沿用
T-2無快取 → POST https://identity.nexar.com/connect/token（Client Credentials flow）
T-3取得 access_token，寫入 Cache（23 小時有效期）

GraphQL 查詢（CallSupSearchMpnAsync）

步驟說明
N-1POST https://api.nexar.com/graphql，GraphQL 查詢 supSearchMpn，country=TW、currency=TWD，傳入 MPN
N-2取 results[0].part，確認 MPN 完全一致
N-3遍歷所有 Seller → Offer → PriceBreak，建立 TBBomFileQuotationExternalHistoryDM 清單
N-4批次寫入：TBBomFileQuotationExternalHistoryBL.BatchInsert(historyDmList)
N-5篩選：MOQ ≤ qty 且 Stock ≥ qty；依供應商取最大 MOQ 的 PriceBreak；依 UnitPriceTWD 升冪排序
N-6優先供應商（configPreferredVendorList）中取最低價；無則從全部取最低價

Mouser 查價（QueryMouserAction）

位置：backend/Common/ExternalQueryExecuteHandler.cs

步驟說明API 端點
M-1以 PartNumber 搜尋 Mouser 料號POST {Mouser}search/partnumber?apiKey={MouserSearchApiKey}
M-2過濾有庫存（AvailabilityInStock > 0）且庫存量 ≥ 需求數量的結果—
M-3對每筆符合料號加入購物車（Session Cart），取得實際下單價POST {Mouser}cart/items/insert?apiKey={MouserCartApiKey}&cartKey=...
M-4從購物車移除（清理 Session Cart）POST {Mouser}cart/item/remove?apiKey=...&mouserPartNumber=...
M-5優先使用購物車實際單價（UnitPrice），Fallback 為定價表（PriceBreaks）—
M-6回傳最低單價結果（MinBy(p => p.UnitPriceTwd)）—

DigiKey 查價（QueryDkAction）

位置：backend/Common/ExternalQueryExecuteHandler.cs

步驟說明API 端點
D-1OAuth2 Client Credentials 取得 TokenPOST {ExternalQueryExecuteUrls:DkToken}
D-2以 Keyword 搜尋（優先 ExactMatches → Products），過濾庫存量 ≥ 需求數量POST {DkQuery}/search/keyword
D-3對每筆以 DigiKey Product Number 查詳細（含 MyPricing 合約優惠價）GET {DkQuery}/search/{dkn}/productdetails
D-4優先 MyPricing（合約優惠價）→ Fallback StandardPricing；取 ≤ qty 的最大 PriceBreak—
D-5回傳最低 UnitPriceOriginalCurrency 結果—

七、結果儲存（HandleQuotationBL）

位置：Business/BusinessLogic/HandleQuotationBL.cs

方法說明使用時機
DoSaveFullSearchResult() 批次儲存查料＋查價，更新 ProcessStatus = PricingDone 排程完成一個上傳檔案
DoSaveSingleInternalQuotationResult() 單筆更新內部查價欄位 + 決策歷程 前端重新內部查價
DoSaveSingleExternalQuotationResult() 單筆更新外部查價欄位 + 決策歷程 前端重新外部查價
DoSaveSingleInStockPriceResult() 刪除舊 TBBomFileQuotationOther → 插入 Mouser + DigiKey 結果 → 寫入決策歷程 前端查現貨優惠價

內部使用的 BL

  • TBBomFileQuotationBL — 查價主表 Upsert / Update
  • TBBomFileDecisionLogBL — 決策歷程寫入
  • EsFileTransferUploadBL — ProcessStatus 更新
  • TBBomFileQuotationOtherBL — Mouser / DigiKey 結果
