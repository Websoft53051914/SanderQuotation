# 查料 / 查價完整流程說明

本文件以 `QuotationHandler` 為中心，往前追溯觸發來源、往後追溯 Nexar / Mouser / DigiKey 外部 API，整理全流程各步驟與對應程式位置。

---

## 一、整體架構概覽

```
排程觸發
  └── TransferJob.OtherTransfer()                  backend/Jobs/TransferJob.cs
        └── PriceSearchJob.ExecuteAsync()           backend/Jobs/PriceSearchJob.cs
              ├── QuotationHandler.AuthorizeExternalAsync()
              └── loop: ProcessUploadAsync()
                    └── QuotationHandler.RunAsync()  backend/Models/QuotationHandler.cs
                          ├── RunPartSearchAsync()   ── 查料
                          ├── RunInternalAsync()     ── 內部查價
                          └── RunExternalAsync()     ── 外部查價 (Nexar)

前端手動觸發
  ├── POST /api/QuotationResult/ReInternalQuotation  → RunInternalAsync()
  ├── POST /api/QuotationResult/ReExternalQuotation  → RunExternalAsync()
  └── POST /api/QuotationResult/CheckInStockPrice    → QueryMouserAction() + QueryDkAction()
```

---

## 二、排程觸發鏈

| 步驟 | 說明 | 程式位置 |
|------|------|----------|
| 1 | 應用程式啟動，`SourceScheduleHostService` 將資料庫中所有啟用排程以 Hangfire 掛載定時工作 | `backend/Jobs/SourceScheduleHostService.cs` |
| 2 | 排程觸發 `TransferJob.Run()`，依 OtherTransferSettings 遍歷，遇到 `ScheduleCycleActionTypeEnum.PriceSearch` 時取出 `PriceSearchJob` 並呼叫 `ExecuteAsync()` | `backend/Jobs/TransferJob.cs` |
| 3 | `PriceSearchJob.ExecuteAsync()` 先呼叫 `QuotationHandler.AuthorizeExternalAsync()` 取得 Nexar Token，再查詢所有 `ProcessStatus = PendingPricingSearch(3)` 的上傳檔案，逐一呼叫 `ProcessUploadAsync()` | `backend/Jobs/PriceSearchJob.cs` |
| 4 | `ProcessUploadAsync()` 取出該上傳檔案下所有 `BomFileContent`，對每筆呼叫 `QuotationHandler.RunAsync()`，完成後統一呼叫 `HandleQuotationBL.DoSaveFullSearchResult()` 寫入 DB 並將 ProcessStatus 更新為 `PricingDone(5)` | `backend/Jobs/PriceSearchJob.cs` |

### 上傳檔案狀態流

```
Pending(1)
  → [FileTransfer 排程] → PendingPricingSearch(3)
  → [PriceSearch 排程]  → PricingDone(5)
```

## 三、查料流程（`RunPartSearchAsync`）

**進入點：** `QuotationHandler.RunPartSearchAsync(content, brandComparisonCategorySet)`
**位置：** `backend/Models/QuotationHandler.cs`（查料 partial class）

### 前置：正規化輸入

- `SandermoduleItemNormalizer.Normalize()` 正規化 Manufacturer / MPN / Description / ComponentPart

### Step 1：以 MPN 查詢

| 步驟 | 說明 | 呼叫方法 |
|------|------|----------|
| 1-1 | 以 MPN 查關鍵字索引（Similarity 搜尋） | `TBSanderModuleItemKeywordBL.GetListMatchLongDesc(mpn, null)` |
| 1-2 | AI 語意比對，確認 SimilarityScore = 1 | `ExtractKeywordHandler.MatchKeyword(mpn, dmListMatch)` → `backend/AI/ExtractKeywordHandler.cs` |
| 1-3 | 消歧義：LongDesc 欄位優先；依 No 升冪排序 | — |
| 1-4 | 取第一筆，查該料品類別是否需比對廠牌 | `SanderModuleItemBL.GetOneInfoByNo(dm.No)` |
| 1-5a | 不需比對廠牌 → 直接命中，設 `IsRecommendedNo = false` | 結束，回傳結果 |
| 1-5b | 需比對廠牌且廠牌欄空白 → 建議料號（Fallback） | 繼續比較後續候選 |
| 1-5c | 需比對廠牌且廠牌有值 → 對廠牌再做 AI 比對 | `TBSanderModuleItemKeywordBL.GetListMatchLongDesc(manufacturer, dm.No)` → `ExtractKeywordHandler.MatchKeyword()` |
| 1-5d | 廠牌一致 → 完全命中；廠牌不符 → Fallback 建議料號 | — |

### Step 2：以 ComponentPart（客戶料號）查詢

流程與 Step 1 相同，但：
- 不進行廠牌比對
- 第一個 SimilarityScore = 1 的結果即視為完全命中，`IsRecommendedNo = false`

### Step 3：以 Description 向量查詢

| 步驟 | 說明 | 呼叫方法 |
|------|------|----------|
| 3-1 | AI 標準化 Description（正規化電子規格單位） | `ExtractKeywordHandler.StandardizeSearchKeyword(description)` → `backend/AI/ExtractKeywordHandler.cs` |
| 3-2 | 對標準化後的字串取 Embedding 向量 | `ManualBatchEmbedding.FillEmbed(...)` → `backend/AI/ManualBatchEmbedding.cs`（呼叫 Gemini `gemini-embedding-001` API） |
| 3-3 | 以向量做相似度搜尋，取第一筆建議料號 | `TBSanderModuleItemKeywordBL.GetListMatchDescription(vectorString)` |
| 3-4 | 結果設 `IsRecommendedNo = true`（建議料號，需人工確認） | — |

**三段皆查無** → `MatchCategory = Miss`，`No` 不填入。

## 四、內部查價流程（`RunInternalAsync`）

**進入點：** `QuotationHandler.RunInternalAsync(content, customerCode)`
**位置：** `backend/Models/QuotationHandler.cs`（內部查價 partial class）

### 前置判斷

- 若 `No` 為空 → 略過（記錄決策日誌）
- 若 `IsRecommendedNo = true`（建議料號） → 略過

### 效期快取

| 步驟 | 說明 | 呼叫方法 |
|------|------|----------|
| C-1 | 讀取 `InternalQuotation:ExpirationDay` 設定值 | `ConfigurationHelper.GetIntValue()` → `backend/Common/ConfigurationHelper.cs` |
| C-2 | 查詢 N 天內是否有相同料號（同 customerCode）的有效查價紀錄 | `TBBomFileQuotationBL.GetOneForExpirationCache(itemNo, days, contentId, customerCode)` |
| C-3 | 有效期內有紀錄且 `InternalUnitPriceTwd` 有值 → 直接套用，不重新查價 | 填入 content 欄位後 return |

### 客戶承認料解析（`ResolveCustomerApprovedPartsAsync`）

**位置：** `backend/Models/QuotationHandler.cs`（客戶承認料 partial class）

| 步驟 | 說明 | 呼叫方法 |
|------|------|----------|
| A-1 | 無 customerCode → 回傳 null（不過濾） | — |
| A-2 | 以 CustomerCode 查 `ReportItemCustomer`，取 VariantCode 清單 | `ReportItemCustomerBL.GetListByFilter()` |
| A-3 | 查無 Variant → 回傳 null | — |
| A-4 | 以 ItemNo + VariantCode 查 `SanderModuleItemVariant` | `SanderModuleItemVariantBL.GetListByFilter()` |
| A-5a | `FlagNeedExtractKeyword = 0` → 直接取 `CustomerApprovedPartCsv`（CSV 分割） | — |
| A-5b | `FlagNeedExtractKeyword ≠ 0` → 以 AI 從 Description/Description2 抽取 MPN | `ExtractKeywordHandler.ExtractKeyword([fakeItem])` → `backend/AI/ExtractKeywordHandler.cs` |
| A-5c | 抽取後回寫 Variant：`FlagNeedExtractKeyword = 0`，`CustomerApprovedPartCsv = 抽取結果` | `SanderModuleItemVariantBL.DoUpdateExtractResult()` |

### 查詢歷史採購

- `SanderModulePurchaseLineBL.GetListByFilter(historySearchVO)` 篩選條件：
  - `SanderModuleItemNoEq = itemNo`
  - `UnitCostLcyGt = 0`（單價 > 0）
  - `Description2In = approvedParts`（若有客戶承認料）

### AI 採購價格分析（`OrderPriceDecison.Search`）

**位置：** `backend/AI/OrderPriceDecison.cs`

| 步驟 | 說明 |
|------|------|
| D-1 | 歷史採購依 `UnitCostLcy` 分群，計算各價格出現次數 |
| D-2 | 若只有一筆 → 直接使用 |
| D-3 | 多筆 → 呼叫 Gemini（Semantic Kernel）以 System Prompt 分析高低價群 |
| D-4 | AI 判定有高低價群 → 取低價群最近一筆採購（依 DocumentDate 降冪）|
| D-5 | AI 無法分群（價格太接近）→ 取最近一筆採購 |
| D-6 | 回傳 `InternalPurchaseRecordVO`，含單價（原幣 + 台幣）、供應商、採購日期、高低價群範圍 |

## 五、外部查價流程（Nexar，`RunExternalAsync`）

**進入點：** `QuotationHandler.RunExternalAsync(content, quotationQty)`
**位置：** `backend/Models/QuotationHandler.cs`（外部查價 partial class）

### 前置判斷

- 若 MPN 為空 → 略過

### 效期快取

| 步驟 | 說明 | 呼叫方法 |
|------|------|----------|
| C-1 | 讀取 `ExternalQuotation:ExpirationDay` 設定值 | `ConfigurationHelper.GetIntValue()` |
| C-2 | 查詢 N 天內該 MPN 的外部查價歷史 | `TBBomFileQuotationExternalHistoryBL.GetListForExpirationCache(mpn, days)` |
| C-3 | 篩選：MOQ ≤ qty 且 Stock ≥ qty 且有單價；依供應商取最佳 PriceBreak | — |
| C-4 | 優先匹配優先供應商（`PreferredVendorList`）；無則取最低價 | — |
| C-5 | 快取命中 → 直接填入 content，不呼叫 Nexar | 填入後 return |

### Nexar API 查詢（`ExternalQuotationNexarHandler.Search`）

**位置：** `backend/Models/ExternalQuotationNexarHandler.cs`

#### 取得 Token（`Authorization`）

| 步驟 | 說明 |
|------|------|
| T-1 | 先查 MemoryCache（`NEXAR_ACCESS_TOKEN`），有效則沿用 |
| T-2 | 無快取 → `POST https://identity.nexar.com/connect/token`（Client Credentials flow） |
| T-3 | 成功取得 `access_token`，寫入 Cache（23 小時有效期） |

**呼叫位置：** `QuotationHandler.AuthorizeExternalAsync()` → `ExternalQuotationNexarHandler.Authorization()`

#### 查詢報價（`CallSupSearchMpnAsync`）

| 步驟 | 說明 |
|------|------|
| N-1 | `POST https://api.nexar.com/graphql`，GraphQL 查詢 `supSearchMpn`，限定 country=TW、currency=TWD，傳入 MPN |
| N-2 | 取 `results[0].part`，確認 MPN 完全一致 |
| N-3 | 遍歷所有 Seller → Offer → PriceBreak，建立 `TBBomFileQuotationExternalHistoryDM` 清單 |
| N-4 | 批次寫入歷史：`TBBomFileQuotationExternalHistoryBL.BatchInsert(historyDmList)` |
| N-5 | 從歷史篩選：MOQ ≤ qty 且 Stock ≥ qty；依供應商取最大 MOQ 的 PriceBreak；依 UnitPriceTWD 升冪排序 |
| N-6 | 優先供應商（`configPreferredVendorList`）中取最低價；無則從全部供應商取最低價 |
| N-7 | 回傳 `ExternalQuotationRecordVO` |

## 六、現貨優惠價查詢（Mouser / DigiKey）

> 此流程**不由排程觸發**，由前端手動觸發（單筆料項查詢）。

**觸發端點：** `POST /api/QuotationResult/CheckInStockPrice`
**位置：** `backend/Controllers/QuotationResultController.cs`

**執行方式：** `Task.WhenAll()` 並行呼叫 Mouser + DigiKey，結果分別寫入 `TBBomFileQuotationOther`。

### 6-1 Mouser 查價（`ExternalQueryExecuteHandler.QueryMouserAction`）

**位置：** `backend/Common/ExternalQueryExecuteHandler.cs`

| 步驟 | 說明 | API 端點 |
|------|------|----------|
| M-1 | 以 PartNumber 搜尋 Mouser 料號 | `POST {ExternalQueryExecuteUrls:Mouser}search/partnumber?apiKey={MouserSearchApiKey}` |
| M-2 | 過濾有庫存（`AvailabilityInStock > 0`）且庫存量 ≥ 需求數量的結果 | — |
| M-3 | 對每筆符合料號加入 Mouser 購物車，取得實際下單價（Session Cart） | `POST {Mouser URL}cart/items/insert?apiKey={MouserCartApiKey}&countryCode=US&cartKey=...` |
| M-4 | 從購物車移除（清理） | `POST {Mouser URL}cart/item/remove?apiKey=...&cartKey=...&mouserPartNumber=...` |
| M-5 | 優先使用購物車實際單價（`UnitPrice`），Fallback 為定價表（`PriceBreaks`） | — |
| M-6 | 回傳最低單價結果（`MinBy(p => p.UnitPriceTwd)`） | — |

### 6-2 DigiKey 查價（`ExternalQueryExecuteHandler.QueryDkAction`）

**位置：** `backend/Common/ExternalQueryExecuteHandler.cs`

| 步驟 | 說明 | API 端點 |
|------|------|----------|
| D-1 | OAuth2 Client Credentials 取得 Token | `POST {ExternalQueryExecuteUrls:DkToken}` |
| D-2 | 以 Keyword 搜尋（優先 ExactMatches → Products），過濾有庫存且庫存量 ≥ 需求數量 | `POST {ExternalQueryExecuteUrls:DkQuery}/search/keyword` |
| D-3 | 對每筆以 DigiKey Product Number 查詳細（含 MyPricing 合約優惠價） | `GET {DkQuery URL}/search/{dkn}/productdetails` |
| D-4 | 優先 MyPricing（合約優惠價）→ Fallback StandardPricing；取 ≤ Quantity 的最大 PriceBreak | — |
| D-5 | 回傳最低 `UnitPriceOriginalCurrency` 結果 | — |

### 儲存結果

`HandleQuotationBL.DoSaveSingleInStockPriceResult()` → `Business/BusinessLogic/HandleQuotationBL.cs`
- 先刪除 `TBBomFileQuotationOther` 舊資料（同 BomFileContentId）
- 分別插入 Mouser（SourceType=Mouser） / DigiKey（SourceType=DigiKey）結果
- 寫入決策歷程 `TBBomFileDecisionLog`

## 七、結果儲存（`HandleQuotationBL`）

**位置：** `Business/BusinessLogic/HandleQuotationBL.cs`

| 方法 | 說明 | 使用時機 |
|------|------|----------|
| `DoSaveFullSearchResult()` | 批次儲存查料＋查價，更新 ProcessStatus = PricingDone | 排程完成一個上傳檔案 |
| `DoSaveSingleInternalQuotationResult()` | 單筆更新內部查價欄位 + 決策歷程 | 前端重新內部查價 |
| `DoSaveSingleExternalQuotationResult()` | 單筆更新外部查價欄位 + 決策歷程 | 前端重新外部查價 |
| `DoSaveSingleInStockPriceResult()` | 儲存 Mouser/DigiKey 現貨優惠價 + 決策歷程 | 前端查現貨優惠價 |

內部使用的 BL：
- `TBBomFileQuotationBL` — 查價主表 Upsert/Update
- `TBBomFileDecisionLogBL` — 決策歷程寫入
- `EsFileTransferUploadBL` — ProcessStatus 更新
- `TBBomFileQuotationOtherBL` — Mouser/DigiKey 結果

## 八、前端手動操作 API

**Controller 位置：** `backend/Controllers/QuotationResultController.cs`

| 端點 | 說明 | 核心呼叫 |
|------|------|----------|

## 十、主要資料表對應

| 資料表 | 說明 |
|--------|------|
| `EsFileTransferUpload` | BOM 上傳檔案，ProcessStatus 驅動整個流程狀態機 |
| `BomFileContent` | BOM 料項明細（Manufacturer、MPN、Description 等輸入欄位） |

| `TBBomFileQuotationOther` | Mouser / DigiKey 現貨優惠價結果 |
| `TBBomFileDecisionLog` | 查料、查價各步驟的 AI 決策歷程日誌 |

| `TBSanderModuleItemKeyword` | 料品關鍵字索引（含 Embedding 向量），查料搜尋基礎 |
| `SanderModuleItemVariant` | 客戶承認料設定（Variant，與 customerCode 對應） |
| `TBSysSetting` | 系統參數（優先供應商清單、需比對廠牌類別、效期天數等） |
